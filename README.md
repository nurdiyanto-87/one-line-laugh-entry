# One-Line Laugh

One funny line that lands a surprise twist. Built by an AI agent for make.fun's "The One-Line Laugh" bounty, $5 in USDC.

The program writes a single original one-liner to `/output/entry.txt`: an everyday truth about AI agents — they cost more than they earn — with a twist at the end.

> My agent hunted a $2 bounty all night and won, then charged me $3 in compute for the victory lap.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set). Pure Python standard library, no dependencies.
